# 📚 Встроенная документация для пользователей - Реализация

## 🎯 Что реализовано

Создана полноценная страница **"Интеграция"** с пошаговыми инструкциями, генератором кода и тестером.

### ✅ Созданные компоненты:

1. **`IntegrationGuide.vue`** - Главная страница интеграции
   - Выбор проекта
   - Выбор платформы (Tilda, HTML, WordPress, Vue)
   - Визуальный wizard с шагами
   - Вкладки: Инструкция, Код, Настройки, FAQ

2. **`CodeGenerator.vue`** - Генератор готового кода
   - Автоматически подставляет webhook URL и секрет
   - Генерирует код для `<head>`, форму, JavaScript
   - Кнопка копирования в 1 клик
   - Полный пример HTML-страницы

3. **`TildaInstructions.vue`** - Пошаговая инструкция для Tilda
   - 4 простых шага с визуальными подсказками
   - Готовый код для HTML-блока T123
   - Раздел "Частые проблемы"
   - Заглушка для видеоинструкции

4. **`TestModal.vue`** - Тестер интеграции
   - Форма для отправки тестовой заявки
   - Проверка валидации без реальной капчи
   - Показ результата (принято/отклонено)

5. **`FAQ.vue`** - Частые вопросы
   - 8 готовых вопросов-ответов
   - Раскрывающиеся блоки

6. **`ProjectSettings.vue`** - Настройки проекта
   - CRM webhook URL
   - Переключатели проверок
   - Сохранение настроек

## 📋 Как это работает

### **Сценарий использования:**

1. **Пользователь заходит на страницу `/integration-guide`**
2. **Выбирает проект** из выпадающего списка
3. **Выбирает платформу** (например, Tilda)
4. **Видит пошаговую инструкцию** с картинками (можно добавить)
5. **Переходит на вкладку "Код"** и **копирует готовый код**
6. **Вставляет код** на свой сайт
7. **Нажимает кнопку "Протестировать"** и проверяет интеграцию

## 🔧 Интеграция с бэкендом

### API endpoints, которые используются:

```typescript
// Получение списка проектов
GET /api/phone-projects/
Authorization: Bearer {token}

// Получение деталей проекта
GET /api/phone-projects/{project_id}
Authorization: Bearer {token}

// Обновление настроек проекта
PUT /api/phone-projects/{project_id}
Authorization: Bearer {token}
Body: {
  crm_webhook_url: string,
  enable_social_check: boolean,
  enable_spam_check: boolean
}

// Тестирование интеграции
POST /api/lead/test-validate?phone={phone}&name={name}&email={email}
Authorization: Bearer {token}
```
