# VK ID: импорт телефона — candidate, не production

Владелец подтвердил включённый расширенный доступ «Номер телефона» в VK ID.
На 22.09.2026 обработка номера реализована локально, **не выложена**.

## Изменение

`backend_api/oauth_login.py` читает `user_info.user.phone` из серверного ответа
VK ID, сохраняет полный номер в `users.phone` при новом аккаунте и заполняет
пустой контакт при существующей VK-связи / привязке / совпадении email.
Существующий пользовательский контакт не заменяет и не стирает.
Номер не используется для связывания аккаунтов и не является доказательством
email-верификации. Конфликт identity проверяется до изменения телефона.

Отсутствующие, маскированные, неверно типизированные/некорректные номера
пропускаются и не блокируют обычную обработку callback. Введённый пользователем
в браузере phone не читается. Номер сохраняется до первого commit нового
пользователя — notification outbox сможет его прочитать после commit.

Для включения на production нужен **узкий backend release** и конфигурация
`VK_LOGIN_SCOPE=email phone`. Текущий безопасный default `email` сохранён для
установок, где разрешение на телефон не одобрено. `.env.example` поясняет opt-in.
Не делать blanket pull/build/up: в ветке есть незавершённый DevOps candidate.
Яндекс/MAX и мобильные правки этим изменением не выкатываются.

## Проверка

41/41 pytest case прошёл в отдельном контейнере на действующем production
image `4ca866ebddc4c3af8b1ef4d2905e099453c6e8b6b768192508991b89e8421219`,
с read-only mount только обновлённого oauth_login.py и теста, network=none,
SQLite memory / dummy SECRET_KEY, без production env/DB/провайдерских вызовов.
Проверены все ветви callback, конфликты, сохранение существующего контакта,
опциональность phone, форматы и запрос scope при явном включении.

Живая приёмка требует нового согласия/входа VK и provider-returned полного
номера; реальный телефон ещё не проверялся. Повторный вход существующего
аккаунта заполнит пустой контакт после выкладки, но **не создаст уведомление
о новой регистрации**.

Источники: официальный [пример scope phone email](https://github.com/VKCOM/vkid-web-sdk/blob/master/README.md),
[UserInfoResult / optional phone](https://github.com/VKCOM/vkid-web-sdk/blob/master/src/auth/types.ts).
