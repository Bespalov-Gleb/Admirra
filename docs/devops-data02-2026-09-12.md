# DATA-02 — устранение двойного знаменателя CPL Авито

Часть T04: точечная подтверждённая ошибка, не завершение всей матрицы DATA-01–03. Подготовлено локально, production не переключён; snapshots отправленных отчётов/AI не перегенерировались.

## Причина и исправление

В `StatsService.aggregate_summary(platform='avito')` `m_q` выбирает цели **Авито**. Их сумма попадала и в `avito_leads_for_cpa`, и в `yandex_convs_for_cpa`. При расходе 500 и 3 выбранных лидах weighted denominator получался 6, хотя числитель — 500. Контрольный тест на исходном `17fd0af` воспроизвёл **83,33 вместо 166,67**.

Теперь Yandex-вклад в знаменатель существует только для `platform=all/yandex`. Авито использует свой расход и выбранные цели ровно один раз. НДС, goal selection, VK lead objectives, native conversions и смешанная продуктовая политика доступности общего CPL не менялись. Расчёт внутри периода остаётся без промежуточного округления; прежний JSON контракт `cpa` округляет итог до 2 знаков.

Новая метка `calculation_version=summary-2-avito-cpl` проходит через `StatsSummary`, новые frozen report JSON и snapshot визита. Старый Avito snapshot визита без этой версии не сравнивается с новым как «CPL вырос с прошлого захода». Сравнение двух свежих версий сохраняется. Другие каналы не затронуты этой защитой.

## Проверенные пути

| Путь | Доказательство |
| --- | --- |
| Общий сервис/summary API | 500 / 3 → 166,67; тест вызывает существующий async endpoint с явным scope resolver и реальной тестовой SQL статистикой |
| Направление | Exact override 2 лида → 250 ₽; предыдущие 3 при расходе 900 → 300 ₽; дельта −50 ₽ / −16,7% |
| Обычный previous period | 166,67 против 300; рублёвая дельта −133,33, процент −44,4% |
| Нижняя Динамика | CPL совпадает со сводкой **при одинаковых границах bucket**; неделя выравнивается по понедельнику, поэтому нельзя сравнивать её лиды с произвольным одним днём |
| Snapshot builder / сообщение отчёта | Новые данные PDF builder содержат 166,67; текст отчёта тоже 166,67 без второго начисления НДС Авито |
| AI-комментарий | Реальный context builder получает 166,67 и 3 лида; платный LLM не вызывался |
| Яндекс/VK/смешанный ТОП | Существующие fixtures: 34, не native 65; VK 6 без 999 traffic; mixed 43 и CPL 4500/43; preserved |

Детектор iteration3 использует собственные SQL/формулы для Яндекса/VK; `_table_for` не включает Авито. Данный дефект не найден в его знаменателе; массовый пересчёт flags не запускался. Это не утверждение, что все остальные detector/scope вопросы уже закрыты. Новый чат-ассистент получает данные отдельными live tools и не вызывает `aggregate_summary`; модель/инструменты этим пакетом не менялись.

## Derived/cache/rollback

Итоги aggregate_summary не находятся в уже подключённом Redis read cache. AI data fingerprint включает числовой context, поэтому изменившийся CPL делает старую генерацию несовпадающей при штатной проверке; дополнительной массовой платной регенерации не запускать. Старые delivery snapshots намеренно неизменны — это исторические отправленные артефакты, а не online отчёт. Version marker нужен для различения нового расчёта и старых сохранённых данных; `data_revision/settings_revision` из T06 он не заменяет.

Деплой — обычный совместимый backend release после общих gates; миграция БД для этого исправления не нужна. Откат кода возвращает известный неверный CPL Авито, поэтому предпочтителен roll-forward. Не менять сырые лиды/расходы ради совпадения с ошибочным baseline.
