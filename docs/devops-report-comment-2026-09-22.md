# Пункт 3: автоматический AI-комментарий отчёта — candidate

Продолжение после `f81e774`. Production не менялся. Новый путь используется
при `REPORT_FRESHNESS_GUARDS=true`; новых миграций в этом пакете нет.

## Что исправлено

- Комментарий строится из уже сохранённого `ReportDelivery.snapshot_data`,
  не из нового чтения статистики после подготовки PDF. В prompt идут summary
  и до 10 top campaigns; лимит сериализованного контекста 64 KiB.
- Денежные значения приводятся к тому же НДС/лидовому расходу, что email-отчёт;
  исходный raw snapshot не изменяется. Avito не получает повторный НДС.
- SQL-транзакция фиксирует снимок и начало попытки **до** AI. Во время LLM и
  PDF/PNG render нет занятого SQL-соединения этого workflow.
- Попытка записана в `delivery_results.automatic_ai_attempt`; повтор доставки
  не запускает второй платный запрос. SDK retries уже отключены.
- Параллельный вызов во время генерации останавливается, а не отправляет
  отличающийся файл без комментария. Ожидание ограничено deadline 5 минут:
  следующий вызов после deadline помечает результат неизвестным и может
  продолжить отправку без AI. Поздний ответ модели уже не публикуется.
- Перед публикацией сравниваются параметры/снимок/согласование/ручной текст.
  Изменения пользователя имеют приоритет. Подтверждение и файлы сохраняются
  короткой fenced-транзакцией; сохранённый receipt переживает send checkpoints.
- Ошибка AI не делает готовый отчёт бесполезным: он может уйти без AI, но
  автоматического платного повтора нет. Содержимое prompt/ответа не записывается
  в новое диагностическое сообщение об ошибке.

## Проверки

Изолированный PostgreSQL, AI и render заменены синтетическими функциями.
Проверены отсутствие SQL во время IO/render, один вызов модели, неизменяемый
контекст, приоритет ручной правки, disabled/manual/approved сценарии, отказ до
AI без готового снимка, concurrent request/deadline, НДС и сохранение receipt.
Финальный расширенный targeted run: **95 passed, 1 deselected** (тест
frontend-файла, не включённого в backend archive), 79,82 с. В том числе реальный
путь подготовки prompt с подменённым транспортом, lost lease, blank approved
comment и send checkpoint. Полный regression фиксируется отдельно после окончания.

## Что не закрывается этим пакетом

Остальные legacy interactive report/AI пути, немедленные lead exports/validation,
tenant isolation старой analytics/blacklist, общая операторская UX-приёмка.
Отдельный найденный SQL-over-IO хвост: offline conversion Метрики в billing
webhook вызывается до финального commit. Новая CP-очередь устраняет гонки
именно CP update/cancel, но не превращает этот analytics hook в durable export.
Никаких новых клиентских отправок, реальных LLM-запросов или production migration
для этих проверок не было. Пункты 1–4 целиком закрытыми не считаются.
